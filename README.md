# Projeto-3-Bimestree
Desenvolvendo um jogo no html e css.

#Descrição
O projeto é um Jogo da Memória. O jogador deve virar duas cartas por vez e encontrar os pares iguais. O jogo conta os movimentos e mostra quantos pares já foram encontrados. Quando todos os pares são encontrados, aparece uma mensagem de vitória.

#Objetivo 
O objetivo do projeto é criar um jogo simples e divertido, além de praticar os conhecimentos de HTML, CSS e JavaScript.

#tecnologias
HTML5 – estrutura da página.
CSS3 – aparência, cores, organização e estilo do jogo.
JavaScript – funcionamento das cartas, embaralhamento, pontuação e regras do jogo.
visul-code: para construção em HTML + CSS
figma - Cria

#Como ultilizar
Baixe ou copie os arquivos do projeto.
Coloque index.html, style.css e script.js na mesma pasta.
Abra o arquivo index.html em um navegador, como Google Chrome ou Microsoft Edge.
Clique nas cartas para encontrar os pares.
Encontre todos os pares para ganhar o jogo.
Para começar novamente, clique em “JOGAR NOVAMENTE”.
